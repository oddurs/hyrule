Rendering outward keeps projects consistent. It does nothing for the library,
and the library is where the value accumulates.

The real editing happens inside a project, mid-task, because a prompt just
failed. If that improvement cannot get home, the library rots into the version
written once in January and every project quietly forks from it.

This milestone closes the circle: versioned assets, drift that refuses to be
ignored, and `hyrule promote` to lift a local fix into the library.
