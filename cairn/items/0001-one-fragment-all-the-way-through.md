The smallest thing that is genuinely useful: one asset kind, carried end to end.

A library of CLAUDE.md fragments on disk. A project that names the ones it
wants. `hyrule apply` writing them into managed regions, and `hyrule diff`
telling the truth about what changed since. No profiles, no skills, no TUI, no
sharing — those are all easier to design once the loop actually runs.

The test of this milestone is not that the commands exist. It is that hyrule's
own repository uses hyrule to manage its CLAUDE.md, and that removing hyrule
would be a downgrade.
