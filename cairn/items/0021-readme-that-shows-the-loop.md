## Problem

The current README describes a hello-world binary. Once the loop runs it should
describe the loop, and it should still describe only what exists.

## Proposal

Six commands in sequence, with real output: create a library, write one
fragment, `hyrule init`, `hyrule add`, `hyrule apply`, then edit the block and
`hyrule diff`. Someone should be able to decide whether they want this in under
a minute.

## Acceptance criteria

- [ ] Every command shown has been run, and the output is the real output
- [ ] No feature described that is not implemented
- [ ] Links to ROADMAP.md for what is coming
